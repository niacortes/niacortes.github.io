# Nia Cortes Portfolio Site

A personal portfolio site showcasing Product Design case studies, built with plain HTML & CSS and hosted on GitHub Pages.

🔗 **Live site:** [niacortes.github.io](https://niacortes.github.io)

## Projects featured
- **SPIDI** — Simplifying the onboarding app for grocery delivery drivers (`spidi.html`)
- **BEREL** — Transforming the way people choose and use color (`berel.html`)
- **ePAK** — Redesigning the shipping experience for growing businesses (`epak.html`)
- **VROOM** — Streamlining the process of call center agents (`vroom.html`)
- **UPS** — Redesigning the way UPSers work (`ups.html`)

## Project structure
```
├── index.html      # Landing page
├── berel.html       # BEREL case study
├── epak.html        # ePAK case study
├── spidi.html        # SPIDI case study
├── ups.html          # UPS case study
├── vroom.html        # VROOM case study
├── style.css         # Shared styles
└── img/              # Images used across the site
```

## Built with
Pure HTML, CSS and sweat. No additional requirements or setup other than a browser and access to the Internet.

## Getting started locally
Clone the repo and open `index.html` in your browser — no build step or dependencies required.

```bash
git clone https://github.com/niacortes/niacortes.github.io.git
cd niacortes.github.io
open index.html
```

## Recommended browser
Chrome (latest), but any modern browser will work.
